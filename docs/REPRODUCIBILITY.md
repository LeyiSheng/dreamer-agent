# 复现与结果记录

## 当前快照验证

根 README 提供安装、CPU 单测和本地资产清点入口。公开准备版本已整合实验主工作目录的自有源码，训练路径见 TRAINING_LOGIC.md 与 TRAINING_SETUP.md。

## 每次实验的记录字段

- 源码 commit、依赖环境、GPU 型号和数量。
- 模型来源、固定 revision、文件 SHA-256、可训练模块。
- 数据版本、原始会话分组、训练/校准/开发/测试划分。
- 随机种子、优化器、学习率、批量、序列长度、更新数。
- 评估环境版本、世界种子、起始状态、频率与时限。
- 原始成功次数、总样本数、失败类型、置信区间和计算预算。

分别记录软件测试、模型预测指标、想象回报和真实环境任务结果。正式评估轨迹与训练数据隔离。公开视频或日志经过隐私与再分发授权检查。

## 发布过程

1. 核对主工作仓库的最新源码与计划，更新公开入口和依赖。
2. 执行测试及 `python scripts/release.py check`。
3. 人工审阅发布清单中的内容、第三方授权和实验描述。
4. 导出源码包，解包后再次运行测试和安装验证。
5. 从经过核对的发布目录创建 GitHub 仓库或发布版本。

发布检查脚本检查选定文件，并检查已有 Git 跟踪文件是否超出清单。若复用有历史的仓库，额外审核全部 Git 历史中的秘密与大文件。
