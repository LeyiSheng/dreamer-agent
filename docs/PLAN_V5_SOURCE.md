# Dreamerv4-MC 完整复现与分层增强实施计划

> 整合版 v5.0｜2026-09-08｜基于原《Dreamer 4 分层增强方案 v4.1》及本次复现讨论。
> 面向实施者：逐阶段执行并记录验收证据；可使用 executing-plans 工作流。本文是研究实施计划，不表示代码已经实现或实验已经通过。

**目标：** 复用 Dreamerv4-MC 预训练世界模型，补齐 Minecraft 智能体的行为克隆、奖励学习、想象强化学习与真实环境评估，再加入技能分层、鲁棒约束和 MCTS 专家迭代，研究离线条件下的中后期任务提升。

**架构：** 默认冻结 Tokenizer 与动力学骨干，在其特征上学习任务条件策略、奖励和价值网络。首先建立手写技能调度的基础系统，随后训练自主高层技能策略，最后通过搜索产生教师分布并蒸馏回策略。

**技术栈：** Dreamerv4-MC、PyTorch/CUDA、VPT 离线数据、兼容 VPT 键鼠动作的 Minecraft 评估环境。版本以首次运行成功后锁定的清单为准。

**规格来源：** 用户提供的 v4.1 方案；Dreamer 4 原论文；Dreamerv4-MC 仓库和权重；RLVR-World 官方项目。引用见文末。

## 1. 复现边界与全局约束

1. 跳过世界模型从零预训练，复用公开权重；这不等于获得了原论文的全部模型和训练流程。
2. 当前 Dreamerv4-MC 公开说明聚焦推理，提供约 430M Tokenizer 和 1.7B Dynamics；训练代码标注 Coming Soon。不能假设其中包含 WM+BC、奖励头或价值头。[1–2]
3. 主线固定离线数据：真实环境只用于预注册评估，不把评估轨迹回流为训练、搜索或奖励标注数据。数据缺失时缩小任务范围，不悄悄改成在线训练。
4. 策略输入使用像素及其历史特征。真实库存、坐标和物品事件只供独立评估器评分；如果提供给策略，必须单列为特权信息实验。
5. 保留复现与增强两条结果线。外挂网络方案称为“基于 Dreamerv4-MC 的 Dreamer 4 方法复现”；不能声明原版数值已复现。
6. 同一世界模型、离线数据划分、动作空间、训练预算和评估协议下比较方法。原论文铁镐 29%、钻石 0.7% 仅作为文献参照。[3]
7. 原方案的铁镐 40–50%、钻石 3–8% 均保留为探索性目标，不能作为已验证预测或首轮工程验收条件。

## 2. 对原优化方案的关键修订

| 原设计 | 整合后的处理 | 原因 |
|---|---|---|
| 低层初始化自 Dreamer 4 WM+BC | 从离线动作监督训练初始策略；获得兼容策略权重后才使用初始化 | 当前已确认的资产只有世界模型组件 |
| 高层状态仅使用当前 z | 使用历史特征 h，以及像素推断的库存信念 b | 单帧潜变量不能保证包含背包与长期任务进展 |
| 起始画面与生成画面的 LPIPS 差异检测漂移 | 改为预测误差校准、数据支持度和语义一致性检查 | 正常转身、行走也会与起始画面差异很大 |
| 宏观时间压缩约 50 倍 | 实测技能平均时长；宏观折扣用 gamma 的持续步数次方 | 决策减少不等于动力学计算减少 |
| 线性 V(OOD)-V(data) 称为 CQL | 更名为风险项；主线采用有界惩罚，CQL 另设 Q 版本消融 | 原式不是标准 CQL，可能使价值无界漂移 |
| symlog return 自动归一化到 [0,1] | symlog 后再显式校准，或只在 PUCT 内使用访问 Q 的范围归一化 | symlog 本身不限定范围 |
| 将模型奖励称为可验证奖励 | 区分真实事件标签、学习奖励和模型内一致性代理 | 生成画面不能证明真实任务已成功 |
| 直接使用 RLVR-World | 主线借鉴奖励对齐思想，不训练世界模型 | RLVR-World 的优化对象是世界模型，和当前主线不同 [4] |

## 3. 系统模块与接口

下面路径为拟新增模块，不是对上游仓库现有文件的声明。第一阶段完成代码审计后再确定上游具体接入位置。

| 拟建模块 | 输入与输出 | 职责 |
|---|---|---|
| adapters/world_model.py | reset(context, seed) → state；step(state, action) → next_state | 包装推演、缓存与随机数状态；禁止把缓存当作共享可变全局对象 |
| adapters/actions.py | VPT 动作 ↔ 模型动作 ↔ 环境动作 | 明确按键集合、鼠标量化、动作持续时间、帧率 |
| data/episodes.py | 原始视频、动作、事件 → 对齐轨迹 | 按完整轨迹划分训练/校准/测试，禁止切片泄漏 |
| data/skills.py | 对齐轨迹 → 技能片段、成功与失败标签 | 建立技能词表、前置条件、结束条件和重叠标签规则 |
| agents/features.py | 像素历史、动作历史 → h、库存信念 b | 保持离线、想象与真实执行的特征定义一致 |
| agents/low_policy.py | h、技能 k → 键鼠动作分布 | 行为克隆和低层想象 RL |
| agents/reward.py | h、k、后继特征 → 奖励与完成置信度 | 使用事件监督、负例和独立校准 |
| agents/high_policy.py | h、b、可行性权重 → 技能分布 | 自主技能选择 |
| training/imagination.py | 数据上下文、策略、世界模型 → 轨迹与更新 | PMPO、价值学习、截断语义与日志 |
| planning/skill_search.py | 根上下文、高层先验、低层策略 → 访问计数 | 随机动力学上的技能级搜索 |
| training/expert_iteration.py | 搜索记录、离线样本 → 蒸馏策略 | 多轮搜索、蒸馏和保留基线约束 |
| evaluation/minecraft.py | 冻结检查点、固定种子 → 真实任务指标 | 与训练器隔离的环境评分 |

统一状态至少包含潜在历史、动作历史、KV cache、位置索引和 RNG 状态。完成标记分为 terminated、timeout、uncertainty_cut，不混为一个 done。每条记录保存 checkpoint、episode、frame、skill、reward_source、duration 和 seed。

## 5. 阶段 P1：数据、奖励与低层行为克隆

### 5.1 数据和技能标签

优先使用 VPT contractor 数据中实际可获取的动作及事件。先核验事件字段覆盖，缺失时从已有离线记录补注或缩小技能集。先做获取木头、制作木板、制作工作台、制作木镐、获取石头等小集合，再逐项核对原论文 20 个任务；不臆造 Table 4 的技能对应。

根据事件定位成功时刻，再向前截取技能片段。保留失败、超时、背景片段和“看见目标但未获得”的困难负例。高层标签必须来自可重建的行为目标；有歧义片段丢弃或使用软标签，不能仅凭最终事件把整段轨迹强行归为一个技能。

### 5.2 表征和初始化

令 h_t=F_phi(x_≤t,a_<t)，其中 F_phi 为冻结表征提取路径。初期可用 Tokenizer 历史加轻量时序网络；若接入动力学隐藏层，固定噪声与读出位置，避免训练和执行特征不一致。库存信念 b_t 由可见 UI 和历史事件预测形成，不能读真实游戏状态。

当前无可确认的兼容 WM+BC 权重，低层策略从离线行为克隆开始：

$$L_{BC}=-E_{D_{skill}}\sum_{n=0}^{L-1}\log\pi_{low}^{(n)}(a_{t+n}\mid h_t,k),\quad L=8.$$

这里定义 L 为预测目标总数，避免原草稿 n=0 到 L 导致 9 个目标的歧义；严格对齐论文版本时记录索引差异。损失对片段结束、episode 边界和无效标签进行 mask。

### 5.3 奖励设计

真实事件提供监督标签 y_t^k；学习奖励模型输出 p_t^k。对每技能报告精确率、召回率、校准误差，尤其关注奖励误报。

主线先使用稀疏完成奖励，不同时叠加多种塑形。想象奖励仅在完成置信度超过技能阈值、满足连续确认且状态一致性通过时触发一次；技能结束或切换后按定义更新完成记忆，防止同一物品反复领奖。

可选塑形作为独立消融：

$$\tilde r_t=r_t^{event}+\eta[\gamma\Phi(h_{t+1})-\Phi(h_t)]-\lambda_u u_t.$$

Phi 是冻结、校准过的进度估计；u 是有界不可信度。该式在学习模型和部分可观测条件下不声称保持最优策略不变。保存每项奖励贡献，避免提升其实来自代理分数膨胀。

- [ ] 完成无泄漏的数据切分、片段和负例构建。
- [ ] 训练策略、奖励头和完成检测器；保存 BC 策略作为固定 prior。
- [ ] 在独立离线集校准每技能阈值，记录置信度不足的处理规则。
- [ ] 在预注册的真实环境子任务上取得初始成功率，作为所有后续比较基线。

**验收：** 初始策略可稳定执行目标短技能；奖励不会把“看到木头”普遍误判为“获得木头”。未通过奖励校准，不进入 RL。

## 6. 阶段 P2：基础 Dreamer 式想象强化学习

先用固定任务或手写技能顺序建立最小闭环，不同时引入高层与搜索。冻结世界模型，训练低层策略和价值网络；部署到真实环境时禁止执行生成画面，只使用真实观测选择动作。

从离线真实上下文开始，交替采样动作和后继潜变量。初期采用短 rollout，并与 BC 混合约束；根据预测可靠性逐步延长。不能把原稿“256 帧”直接当作已核实的原论文想象 horizon：训练序列长度、上下文长度、想象长度需分别登记。

价值使用 TD/lambda-return；策略沿用 PMPO 的正负优势分组和固定 BC prior：

$$L_\pi=-\alpha_p E_{A\ge0}\log\pi(a|h)+(1-\alpha_p)E_{A<0}\log\pi(a|h)+\beta_{KL}E_h KL(\pi\Vert\pi_{BC}).$$

正负组为空时跳过该组，不除零；优势用于分组时停止梯度。初始 alpha_p=0.5、beta_KL=0.3 是沿用原论文的候选值，需验证动作分量求和后的尺度。

- [ ] 实现轨迹生成、lambda-return、PMPO 和冻结 prior。
- [ ] 验证世界模型参数无更新、目标值无意外梯度、episode 边界不串联。
- [ ] 分别记录想象奖励、预测不可信度、真实成功率及单位 GPU 小时提升。

**验收：** 至少一个短任务在相同评估协议下相对 BC 有可重复提升。模型内奖励上升但真实表现下降时，回到奖励或动力学诊断，不进入更复杂方案。

## 7. 阶段 P3：技能分层与鲁棒约束

### 7.1 Options 与持续时间

高层观测为 s_m^H=(h_{t_m},b_{t_m})，动作是技能 k_m；低层按该技能执行，直至完成、真实失败、超时或不可信截断。高层 BC 从技能段转移初始化。先冻结低层只训高层，稳定后才交替训练并固定对方检查点。

宏观奖励与折扣必须按实际持续低层步数 d_m 聚合：

$$R_m=\sum_{j=0}^{d_m-1}\gamma^j\tilde r_{t_m+j},\quad\Gamma_m=\gamma^{d_m},\quad y_m=R_m+\Gamma_m(1-done_m)V_H(s_{m+1}).$$

高层 lambda-return 同样使用 Gamma_m，不能直接把每技能折扣设为 0.997。帧率或 action repeat 改变时同步换算折扣时间尺度。

### 7.2 漂移、不确定性与截断

离线校准阶段可以比较相同动作条件下的预测帧与真实未来帧；自由想象时没有真实未来，不能继续计算这种监督误差。

在线于模型内的代理 u 可组合：多次随机预测的任务语义分歧、历史特征的数据支持度、物品/动作前置条件冲突。它们只是风险信号，不等于可靠的模型误差估计；需在离线留出集检验其与真实预测错误的相关性。阈值按任务和时长校准，p95 仅为初始候选。

不可信截断采用首版保守规则：舍弃被判不可信的转移，保留此前有效前缀；前缀末端用停止梯度且有界的价值估计自举。单独记录截断率，禁止把被截断后未知奖励标成真实失败。超时和真正终止分别处理。

### 7.3 技能可行性约束

由库存信念与已知前置条件计算技能可行性 c_k(h,b)。高置信不满足条件时硬 mask；不确定时用软惩罚，避免错误库存识别屏蔽唯一可行行为：

$$\tilde\pi_H(k|h,b)\propto\exp[\ell_k-\lambda_m(1-c_k)].$$

所有技能被屏蔽时回退到观察/安全重选行为，并记录发生率。该词表与前置条件仍是人工先验，prompt-free 仅指移除手写技能执行序列。

### 7.4 保守价值

主线不采用原稿未约束的线性 V 差值。可在 TD 上加入高风险状态价值上界惩罚：

$$L_V=L_{TD}+\alpha_u E_h[w(u_h)\max(0,V(h)-U(h))^2].$$

U 是按奖励范围、有效 horizon 和低风险离线回报校准的上界；该设计是待验证的风险正则，不称为标准 CQL。如果单独实现高层 Q，可追加离散动作 CQL 型项 logsumexp_k Q(h,k)-E_{k~D}Q(h,k)，另做超参数与偏差分析。

- [ ] 训练高层 BC，比较手写调度与自主调度。
- [ ] 加入按持续时间折扣的宏观 RL，先不加风险约束。
- [ ] 分别加入可行性约束、不可信截断和保守价值，再评估组合。

**验收：** 同条件下分层系统改善中期任务或到达时间；不以铁镐超过 40% 为硬门槛。检查技能频繁切换、奖励重复触发和技能超时占比。

## 8. 阶段 P4：MCTS 搜索增强与专家迭代

节点包含足够重建世界模型上下文的信息，不能只保存单帧 z。高层策略提供先验，低层技能执行器和世界模型提供随机宏观转移，高层价值评估叶节点。

$$k^*=\arg\max_k\left[Q(s,k)+c_{puct}\pi_H(k|s)\frac{\sqrt{N(s)}}{1+N(s,k)}\right].$$

采用随机后继采样或机会节点处理生成随机性，不把一次“幸运成功”视为确定转移。回传使用 R_m 和 Gamma_m。PUCT 中 Q 的范围归一化只影响选枝，真实回传值保持原尺度；symlog 不直接映射到 [0,1]。

根访问次数生成教师分布：

$$q(k|s)=\frac{N(s,k)^{1/\tau}}{\sum_jN(s,j)^{1/\tau}},\quad L_{distill}=-E_s\sum_kq(k|s)\log\pi_H(k|s).$$

**专家迭代循环：** 从离线训练上下文采根 → 当前高层策略引导有限预算搜索 → 过滤高风险分支 → 保存教师分布和回报 → 混合原始高层 BC 数据蒸馏 → 在离线验证集检查退化 → 固定新版本并进入下一轮。搜索产生的是模型内教师，不是真实环境专家标签。

- [ ] 首轮只搜索少数技能，固定节点数和模型调用数；同时测试深度 2 与 5。
- [ ] 验证克隆后的缓存和随机状态互不污染；记录每根 GPU 秒数。
- [ ] 比较无搜索策略、搜索教师和蒸馏学生，判断教师是否提供有效增益。
- [ ] 先完成一轮，再决定是否追加迭代；不因模型内分数上涨无限搜索。

**部署：** 真实画面 → 历史表征 → 高层技能 → 低层键鼠动作 → 真实 Minecraft；学生不运行 MCTS。若动力学特征读出是策略的一部分，部署仍需相应骨干前向，不能声称仅 Tokenizer 即可完成。

**验收：** 蒸馏后无搜索学生在相同预算下优于分层基线，且尽量保留教师收益；报告离线搜索总成本，不只报告部署速度。

| S0 | H2＋推理时搜索 | 教师能力上界参考 |
| S1 | 搜索蒸馏学生，无在线搜索 | 专家迭代与部署收益 |

同时报告木头、石镐、铁镐、钻石成功率与到达时间、技能完成率、奖励误报、截断率、搜索成本。失败 episode 的时间使用删失/失败率报告，避免只比较成功样本导致偏差。

用至少 3 个训练随机种子检查稳定性。试运行用小规模固定评估集排错；正式候选在未参与调参的随机世界集合评估。对稀有钻石事件优先按原论文量级规划每方法 1000 episodes，并报告成功次数和二项置信区间；预算不足时明确统计不确定性。1000 个 60 分钟 episode 是 1000 环境小时上限，不等于 1000 墙钟小时，需实测并行环境吞吐量。[3]

原稿目标表保留为假设：阶段一铁镐 40–50%、钻石 1–3%；阶段二铁镐 50–60%、钻石 3–8%。实际能否达到取决于复用权重能力，不对这些区间作承诺。单次成功录像不能作为复现成功证据。

## 10. 算力、超参数与时间安排

仓库所列 Dynamics 约 9 GB、Tokenizer 超过 2 GB 是组件推理参考，不是训练总显存保证。优先实测单卡小 batch，再决定是否增加 GPU。无用户硬件信息时不承诺固定显存、费用或训练时长。[1]

总模型推演量粗估为 N_updates × batch × horizon；搜索额外约为 N_roots × simulations × depth × 平均技能时长，实际以展开/复用统计为准。技能抽象压缩决策次数，不会自动免去每个低层动作的模拟成本。

| 参数 | 初始候选 | 使用规则 |
|---|---|---|
| MTP 目标数 | 8 | 明确索引与边界 mask |
| 微观 gamma | 0.997 | 只在匹配时间步定义时沿用 |
| PMPO 正组权重 | 0.5 | 区别于风险正则系数 |
| KL prior 系数 | 0.3 | 固定 BC prior，独立调校 |
| 想象长度 | 16→32→64 步 | 根据可靠性延长，不默认 256 |
| 风险阈值 | 校准集分位数 | 分技能、分预测时长记录 |
| 保守项强度 | 0、0.1、0.5 | 原 0.5 仅作候选 |
| PUCT 系数 | 1.25 | 配合 Q 范围校准 |
| 搜索深度 | 2→5 技能 | 同时限制模型调用总量 |
| 蒸馏温度 | 1.0 | 首轮固定，再作消融 |

以下为工程排期估计，假设已有 RL 开发能力、可用 GPU 和数据；不包含大规模排队、权重修复或重新训练世界模型的时间。

| 周期 | 内容 | 进入下一阶段的条件 |
|---|---|---|
| W1–2 | P0 审计、推演和环境接入 | 动作与缓存正确、短交互可用 |
| W3–4 | P1 数据、奖励与 BC | 策略能执行，奖励可校准 |
| W5–6 | P2 基础想象 RL | 短任务真实提升 |
| W7–9 | P3 高层与鲁棒约束 | 中期任务收益可重复 |
| W10–12 | P4 搜索和蒸馏 | 教师和学生均有有效收益 |
| W13–16 | 稀有事件评估、消融和报告 | 结论有置信区间与预算依据 |

原 8 周排期仅适合作为已有数据、奖励与 BC 系统后的增强阶段估计，不作为从当前推理仓库开始的总工期承诺。

## 11. 失败分流与完成定义

- 世界模型基本交互不可靠：缩小为可靠任务集；若必须适配世界模型，作为独立分支报告，主线“全程冻结”的条件随之变化。
- BC 本身不会执行技能：先处理动作映射、数据覆盖与标签；MCTS 无法替代缺失的低层能力。
- 想象奖励上升而真实回报下降：审查奖励误报、模型错误和分布偏移，缩短 rollout、增强 prior；不要先扩大搜索。
- 搜索有收益、蒸馏无收益：检查根状态覆盖、教师置信度、蒸馏容量和训练分布；分别报告教师与学生。
- 钻石样本过少：主要结论落在可统计的中期里程碑，不以未显著的钻石提升夸大贡献。

**基础复现完成：** 已用冻结世界模型建立 BC、奖励、想象 RL、真实评估闭环，并展示可重复的真实收益。

**增强完成：** 分层与风险约束的独立贡献可辨识，搜索教师增益能部分内化到无搜索学生，所有结果保留数据/权重版本和计算预算。

**RLVR-World 可选扩展：** 若后续决定优化世界模型本身，利用离线真实后继观测提供预测质量或语义转移奖励，单列后训练方案及成本。不能直接假设其离散 token RL 目标适用于本项目的连续潜变量/扩散实现，需要重新推导优化接口；不纳入本轮冻结世界模型主线。[4]
